# 시연 영상 대본 (가로 화면, 약 2분, 유튜브 "공개")

녹화: 화면 기록(Cmd+Shift+5) → 전체 화면, 브라우저에 `streamlit run app.py` 화면.
자막: 장면마다 아래 "화면 자막"을 크게 넣기 (AI 심사가 영상을 덜 읽어도 내용이 전달되게).

| 시간 | 화면 | 말할 내용 | 화면 자막 |
|---|---|---|---|
| 0:00~0:15 | 앱 첫 화면 | AI로 홍보 글은 빨리 쓰지만, 올려도 되는 글인지 확인하는 일은 그대로입니다. 근거편집장은 그 확인까지 합니다. | 근거편집장 · 출처를 짚고 쓰는 B2B 홍보 원고 AI |
| 0:15~0:40 | ① 자료 폴더 입력 → 차별점 분석 | 티링크 제안서와 매뉴얼 3종을 넣으면 차별점마다 원문 인용을 붙이고, 코드가 그 인용이 실제 그 쪽에 있는지 대조합니다. | 차별점 8개 · 원문 인용 확인 8개 |
| 0:40~1:05 | ② 현장 사진 5장 → 원고 생성 | 사진 장면을 읽고 맞는 기능을 연결해 블로그 리뷰 글과 카드뉴스를 씁니다. 카드 첫 장은 고객 질문으로 시작합니다. | 사진 5장 → 블로그 2,510자 + 카드뉴스 5장 · 40초 |
| 1:05~1:35 | ③ 검수 결과 표 + '다른 원고 검수'에 일반 GPT 초안(samples/baseline/draft_2.md) 붙여넣기 | 가이드라인 17개 항목을 검사합니다. 가이드라인은 PC폰 동시 녹음을 강조하지만 매뉴얼 16쪽은 삼성 070 계정만 녹음된다고 합니다. 이런 충돌도 잡습니다. | 일반 GPT 초안: PC폰 조건 위반 3편 중 3편 · 근거편집장: 15/17 + 사람 입력 2, 위반 0 |
| 1:35~1:55 | 자동 수정 버튼 → 재검수 | 미통과 부분만 고쳐 다시 검사합니다. | 붙여넣은 일반 GPT 초안 → 미통과만 자동 수정 → 재검수 |
| 1:55~2:05 | 원고 내려받기 | 게시는 담당자가 확인한 뒤 직접 합니다. 다른 회사도 규칙 파일과 자료만 바꿔 씁니다. | 규칙 파일만 바꾸면 다른 B2B 회사도 사용 |
